# DeepControl v1.1

Расширение (Chrome / Edge / Brave, Manifest V3): официальный чат DeepSeek (chat.deepseek.com, без API) управляет твоим браузером.

## Установка / обновление
`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `DeepControl`
(при обновлении: нажми ⟳ у расширения и **перезагрузи вкладку DeepSeek**).

## Использование
1. Иконка DeepControl → выбери вкладку → «Назначить целевой» (для SAFE-режима).
2. Открой chat.deepseek.com (лучше в отдельном окне). Справа внизу — панель.
3. «Вставить промпт» → допиши задачу после `MY TASK:` → отправь.
4. DeepSeek отвечает JSON-блоком → «Выполнить» (или авто-режим) → результат и скриншоты возвращаются в чат сами.

## Режимы
| | SAFE (по умолчанию) | FULL (FullControl) |
|---|---|---|
| Вкладки | только выбранная (+ открытые из неё) | любые вкладки и окна |
| Сайты | только сайт выбранной вкладки (переходы на другие блокируются, в т.ч. по кликам) | любые |
| Доп. команды | — | list_tabs, switch_tab, close_tab, new_window, go_forward, reload, `tab_id` в любом действии |
| Промпт | `prompt.txt` | `prompt_fullcontrol.txt` |

Переключатель — в попапе и в панели. После смены режима вставь промпт заново. `close_tab` всегда требует подтверждения. DeepSeek не может управлять собственной вкладкой чата.

## Что исправлено в 1.1 (команды не распознавались)
- Парсер стал толерантным: понимает `{"actions":[…]}`, голый массив, одиночную команду; синонимы (`goto/open_url→navigate`, `input/fill→type`, `scroll_down`, `take_screenshot`, `finish→done` и др.); `action/command/name` вместо `type`; `element_id/index` вместо `id`; «умные» кавычки и висячие запятые; JSON вне ```-блока.
- Неизвестная команда → DeepSeek получает ошибку со списком допустимых.
- Новый детектор ответов: не требует «роста» текста, не выполняет старую историю при смене чата, защищён от повторов.
- Кнопки **Диагностика** (что нашлось: сообщения, поле ввода, распознана ли команда) и **Скан** (принудительно разобрать последний ответ).

## Ограничения
- DeepSeek, скорее всего, читает картинки через OCR, поэтому главный канал — `get_page`.
- Селекторы сайта — в `CFG` (`deepseek.js`). Если «Диагностика» пишет, что ответов 0 — пришли мне HTML ответа.
- События синтетические (`isTrusted=false`): часть сайтов может их игнорировать.
- Не используй FullControl + авто-режим на задачах с чувствительными данными: названия и URL всех вкладок уходят на серверы DeepSeek.
